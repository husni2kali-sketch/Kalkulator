Program Studi D3 Teknik Informatika

Merupakan program pendidikan vokasi yang dirancang untuk menghaislkan lulusan yang memiliki keterampilan praktis dibidang teknologi informasi. Program studi ini berfokus pada penguasaan teknologi komputer, pemograman, pengembangan perangkat lunak, jaringan komputer, dan sistem basis data.

Visi

“Menjadi program studi unggulan dalam pengkajian dan penerapan IPTEK pada bidang Informatika dan mampu berkontribusi bagi masyarakat di tingkat nasional.”

Misi

  • Menyelenggarakan pendidikan di bidang informatika untuk menghasilkan tenaga profesional yang adaptif terhadap perkembangan teknologi.
  • Melaksanakan penelitian dasar dan/atau terapan di bidang informatika.
  • Memberikan pelayanan dan pengabdian kepada masyarakat dalam bentuk produksi dan jasa berbasis informatika.
  • Membentuk lulusan yang memiliki jiwa kewirausahaan berbasis teknologi.

Teknologi yang Digunakan

  • HTML untuk struktur halaman
  • CSS untuk tampilan
  • JavaScript untuk interaksi
  • Git dan GitHub untuk kolaborasi tim
  • GitHub Pages untuk publikasi website
